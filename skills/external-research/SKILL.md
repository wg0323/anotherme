# 外部信息检索规范

**需要外部权威信息时：先查官方来源；官方结果不理想时，才降级参考辅助性质的博客/社区文章。**

## 适用场景（包括但不限于）

- 工具/命令行用法与参数（kubectl、node/npm、docker、git、nginx 等）；
- 版本兼容性与对应关系（框架 ↔ 运行时/依赖的版本矩阵）；
- 配置项名称、取值与默认值；
- 依赖/类库/第三方平台 API 用法与行为语义；
- 报错排查（错误信息的官方解释、已知问题）；
- 版本升级与迁移（Breaking Changes、废弃 API 迁移指南）；
- 安全漏洞与修复版本（CVE、官方安全公告）；
- 规范/标准原文与官方推荐做法（RFC、W3C、官方最佳实践）；
- 开源协议条款原文。

## 来源优先级

1. **官方来源（第一优先）**：官网文档、官方仓库（README / Releases / Changelog / Wiki / Issue）、官方公告、规范原文；
2. **辅助资料（降级参考）**：官方来源不存在、未覆盖该问题或与所用版本不匹配时，才参考技术博客、社区文章等；只作参考线索，关键结论必须与官方来源交叉验证。

## 检索与引用要求

- 用 `site:` 限定官方域名（如 `site:kubernetes.io`），或直接访问已知官方文档地址，不依赖搜索引擎自然排序；
- 关键结论注明来源出处；官方来源与辅助资料冲突时，一律以官方为准。
