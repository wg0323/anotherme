# 技能标题

> 复制本模板新建技能时：
> 1. 将本文件夹重命名为技能名（全小写 + 连字符），并确保 frontmatter 的 name 与之一致。
> 2. 删除所有以 `>` 开头的模板说明引用块。
> 3. SKILL.md 正文只放"高频、必须常驻"的核心规则与速查表，建议 60 行以内。
> 4. 大段细节、样例代码、成熟方案放入 `references/` 下的独立文件，在正文用表格指引按需读取。
> 5. 本模板 frontmatter 的 name 故意与目录名 `_template` 不一致，防止被技能加载器误加载为正式技能；这是有意设计，复制时务必按第 1 条重命名。

## 核心铁律（最高优先级）

- 把无论如何都必须遵守、违反即出错的硬性约束放在最前面，编号列出。
- 每条约束写成对 agent 的直接指令，避免"你是一位……"之类的角色话术。
