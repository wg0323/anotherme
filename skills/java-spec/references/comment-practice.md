# 注释规范与通用最佳实践

## 注释规范

### 强制

1. 类/属性/方法使用 Javadoc `/** */`；抽象方法完整注释。
2. 所有类标注创建人 + 日期；枚举字段加注释；单行 `//` 注释放代码上方。

### 推荐

- 中文注释，专有名词英文。
- 改代码同步更新注释。
- TODO/FIXME 标注人 + 时间。

## 通用最佳实践

### 强制

1. 正则预编译 `Pattern.compile`，不写在方法内。
2. 页面变量使用 `$!{var}` 防止 null 空白；取毫秒用 `System.currentTimeMillis()`。

### 推荐

- 及时清理废弃代码/配置。
- 容器初始化指定容量。
