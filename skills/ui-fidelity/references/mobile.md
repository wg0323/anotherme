# 移动端模板二次开发细则

> 适用：uni-app、微信小程序、H5 移动端项目，基于开源模板二开。
> 前置：先按 `template-onboarding.md` 完成侦察，再读本文件。
> 边界：本文件只管**视觉一致与组件复用**；语法、页面生命周期、工程结构以 `uniapp-spec` / `wx-miniapp-spec` 技能为准。

## 一、与 PC 中后台的根本差异

| 维度 | PC 中后台 | 移动端 |
| ---- | --------- | ------ |
| 主体结构 | 搜索 + 表格 + 分页器 | 列表 + 下拉刷新 + 触底加载 + 空态 |
| 尺寸单位 | px / rem | rpx 为主（以模板为准，禁止同一量级混用 px 与 rpx） |
| 导航 | 布局壳固定 | 原生导航栏或自定义导航栏，二选一 |
| 弹层 | 居中对话框 | 半屏弹层 / 新页面跳转 |
| 交互态 | hover / focus | 必须提供点击态；hover 不能作为唯一反馈 |
| 底部 | 无特殊约束 | 安全区 `env(safe-area-inset-bottom)` |

**最高频的违和**：把 PC 的表格、多列布局、hover 效果直接搬到移动端。

## 二、三类页面骨架

**列表页**

- 结构：搜索/筛选条 → 列表项 → 加载更多 → 空态
- 必须：空数据占位、加载中状态；优先沿用基准页的加载与列表模式，模板有下拉刷新时一并保留
- 模板没有既定模式时推荐触底加载；不要为了套规则而把模板已有的分页或数据表改成另一种交互

**详情页**

- 结构：主图/轮播 → 关键信息块 → 富文本或参数区 → 底部操作栏
- 必须：底部固定操作栏预留安全区
- 禁止：PC 式左右分栏

**表单页**

- 结构：分组表单项 → 提交按钮
- 必须：键盘弹起不遮挡输入框、校验提示就近显示
- 禁止：PC 式多列表单

## 三、适配红线

1. **单位**：跟随模板基准。禁止用 px 表达本应 rpx 的间距，导致不同机型比例失衡。
2. **1px 边框**：沿用模板既有写法（`transform: scaleY(0.5)` 或直接 1px），不要自创方案。
3. **安全区**：所有底部固定元素必须处理 `env(safe-area-inset-bottom)`，或使用模板封装的等价类。
4. **滚动**：页面滚动与内部列表滚动只保留一层，禁止嵌套滚动。
5. **点击热区**：可点元素热区不小于 44×44px；视觉尺寸可以小，热区必须够。
6. **图片**：固定宽高比 + 懒加载，避免加载完成后页面跳动。

## 四、移动端违和点速查

| 违和来源 | 典型表现 | 正确做法 |
| -------- | -------- | -------- |
| PC 组件误用 | 用 `el-table` 做列表 | 用卡片列表 |
| 字号 | 正文小于 14px | 跟随模板基准，正文不小于 14px |
| 间距 | 沿用 PC 的 24px 大留白 | 用移动端的紧凑间距 |
| 交互 | 只写 hover，触屏没有明确反馈 | 提供 `:active` 等点击态；是否保留 hover 按模板和输入设备处理 |
| 图标 | 引入 PC 图标集 | 跟随模板图标方案 |
| 弹层 | 居中大弹窗 | 半屏弹层或新页面 |
| 遮罩 | 自造半透明黑底 | 用模板封装的遮罩层 |

## 五、基线文件在移动端的填法

使用当前移动端项目的独立基线文件，不与 PC 共用；路径按 `SKILL.md` 的基线定位规则确定。其中三节按移动端填写：

| 章节 | PC 填法 | 移动端填法 |
| ---- | ------- | ---------- |
| 第 2 节 基准页 | 列表 / 表单 / 详情 | 列表页、详情页、表单页（各挑一个真实页面） |
| 第 4 节 组件白名单 | 表格、工具栏、弹窗 | 商品/内容卡片、规格弹层、空态组件、导航栏组件 |
| 第 5 节 布局约定 | 间距与卡片包裹 | 单位约定、安全区写法、导航栏方案、滚动容器 |

## 六、与技术栈技能的分工

两个技能同时命中时，按维度取规则，不要互相覆盖：

| 维度 | 以谁为准 |
| ---- | -------- |
| 视觉一致、骨架对齐、组件复用、禁止项 | 本技能 |
| JS 语法、页面生命周期、分包、跨端 API 封装 | `uniapp-spec` / `wx-miniapp-spec` |

冲突时先保证代码在该技术栈下可运行，再按本文件调整视觉。
